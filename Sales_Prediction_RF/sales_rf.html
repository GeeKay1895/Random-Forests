Random Forest is an ensemble learning algorithm that combines multiple Decision Trees to improve prediction accuracy and reduce overfitting.

Each tree contributes to the final prediction through majority voting.

Ensemble learning improves model stability by combining predictions from multiple models instead of relying on a single Decision Tree.
